# Frontend

React + Vite client for **EstateLink**. Full setup instructions, features and API reference live in the [project README](../README.md).

```bash
npm install
npm run dev     # start dev server (http://localhost:5173)
npm run build   # production build
npm run lint    # eslint
```

- Routing and data loaders: `src/App.jsx`, `src/lib/loaders.js`
- API base URL: `src/lib/apiRequset.js`
- Styling: SCSS in `src/scss/` plus component-level `.scss` files
